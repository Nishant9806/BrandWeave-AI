# BrandWeave AI — MVP Scope

## 1. Project Objective

BrandWeave AI is an evidence-driven brand-governance platform that analyses submitted content against approved brand guidelines, detects violations, suggests corrections and supports human approval.

## 2. Target Demonstration Organisation

Organisation: TechNova

Product: SmartWatch Pro

Approved Information:
- Product Name: SmartWatch Pro
- Battery Life: 24 hours
- Price: ₹1,499
- Brand Tone: Professional, Friendly, Informative
- Prohibited Claim: India's No. 1
- Prohibited Claim: Guaranteed to transform your life

## 3. User Roles

### Admin
- Access Brand Vault.
- Add and manage approved brand facts.
- Manage preferred and prohibited terminology.
- View submissions and analytics.

### Creator
- Submit content.
- Run brand compliance analysis.
- View detected findings.
- Accept or reject suggested corrections.
- Submit revised content for approval.

### Manager
- View pending approvals.
- Review submitted content.
- Approve or request changes.
- Add review comments.

## 4. Core Features — P0

1. Brand Vault with approved facts and terminology.
2. Text-based content submission.
3. Deterministic terminology checking.
4. Factual claim verification.
5. AI-powered tone and claim analysis.
6. Unified findings report.
7. Severity and confidence indicators.
8. AI-generated correction suggestions.
9. Accept/reject correction functionality.
10. Creator-manager approval workflow.
11. Content version history.
12. Basic activity dashboard.

## 5. Deferred Features

The following features will not block the Round 2 MVP:

- Advanced image compliance.
- Logo detection.
- Advanced visual analysis.
- External integrations.
- Advanced analytics.
- Enterprise authentication.
- Complex multi-organisation administration.

## 6. Main Demonstration Workflow

Admin configures TechNova brand information.

Creator submits an advertisement.

BrandWeave analyses the advertisement using deterministic rules and AI.

The system displays evidence-linked findings.

Creator accepts or rejects suggested corrections.

Creator submits the revised content for approval.

Manager reviews and approves or requests changes.

System maintains version history and audit records.

## 7. Acceptance Criteria

The MVP is considered functional when a judge can:

1. Open the deployed application.
2. Access the demonstration workspace.
3. View approved brand information.
4. Submit an advertisement.
5. Run the review engine.
6. View explanations and evidence for detected issues.
7. Apply suggested corrections.
8. Submit content for approval.
9. Approve or request changes as a manager.
10. View the content's revision history.

All core operations must work without developer assistance.
